# Welcome to Thrylos

Thrylos is a Move-based proof-of-stake L1, written in Rust, currently running as a public alpha testnet. The testnet coin has no value — it exists to let people build and break things safely, not to be traded.

**The testnet is live now.** Four validators, one-second blocks, and Move packages can publish, be called, and keep state.

## Get started

1. **Get testnet coins** — ask `/faucet` in the [Discord](https://discord.gg/).
2. **Make a wallet** — `thrylos setup`, from the [GitHub repo](https://github.com/thrylos-labs/thrylos-rust).
3. **Write your first Move package** — the [developer guide](./move-guide.md) walks through publishing, calling, and storing state.

Also useful: the [explorer](https://explorer.thrylos.org) to browse blocks and accounts, and the [wallet](https://wallet.thrylos.org) for a browser-based account.

## Expect resets

This is an alpha: the testnet is reset — every balance, name and package wiped — whenever a change needs it. That has happened several times already and will happen again. Nothing on it should be treated as permanent, and there is no token sale: see [About Thrylos](./about.md).
